# Weighted-dropout epistemic-set pilot

Generated by `../../dappr_epistemic_sets.ipynb` on 2026-10-28.
The original notebook outputs remain empty for step-by-step use.

The four models were trained independently on within-dataset ID classes only.
The notebook adapts DAPPr's training/evaluation workflow, replaces the
possibilistic objective with dropout cross-entropy, and uses a Probly Representer
returning per-input lower/upper mutual-information bounds over
`w=(1-rho)/T + rho*q`, with `q` in the simplex. Defaults: rho=0.5, T=20.
The scalar score is the interval midpoint. Weights vary pointwise per input.

## Results

| Dataset | ID accuracy | Midpoint OOD AUROC | Ordinary dropout EU AUROC |
| --- | ---: | ---: | ---: |
| MNIST | 0.9750 | 0.8815 | 0.8974 |
| EMNIST | 0.9346 | 0.7943 | 0.8134 |
| Fashion | 0.9475 | 0.6675 | 0.6928 |
| Blood | 0.9100 | 0.4937 | 0.4822 |

No consistent midpoint improvement is established. Blood is near chance.
These are one-seed pilot estimates; Fashion repartitions its cached official
test pool and is not an official benchmark result. OOD classes are listed in
`class_roles.csv`; exact source-image assignments are in `assignments.csv`.

## Figures and numerical limits

- `epistemic_limits.png` / `.pdf`: per-image ID/OOD lower and upper limits,
  interval midpoint, ordinary dropout EU, and attained upper endpoints.
- `mean_epistemic_limits.png`: group-mean endpoint values, not confidence intervals.
- `image_epistemic_sets.png`: image examples with their EU intervals.
- `rho_sensitivity.png`: mean endpoint curves on fixed dropout predictions.

The lower bound is a vertex minimum. The outer upper bound comes from
concavity and a Frank-Wolfe tangent gap; the feasible upper witness is reported
separately. 33 of 5400 test rows exceeded the requested 1e-5-nat optimization
gap; the largest gap was about 1.91e-4 nats. Returned outer bounds remain in
place for those rows rather than silently treating an unconverged feasible
maximum as the upper endpoint. See `scores.csv` for every gap.
These are numerical bounds conditional on the declared finite dropout family,
not confidence/credible intervals for true epistemic uncertainty.

All default notebook cells executed successfully. Six independent numerical
and state-restoration tests passed in `tests/test_epistemic_weight_set.py`.
The helper computes weighted MI with Probly entropy primitives explicitly:
the installed Probly 0.9.0 sample-MI path ignores supplied sample weights.
